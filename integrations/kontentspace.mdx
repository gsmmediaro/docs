<Warning>
  Kontentspace was a community-built connector that let a Kontentspace AI agent call the Kolaria MCP server with a Kolaria API key. As of September 2026 the Kontentspace website and its connections page are unreachable, so this integration can no longer be set up. Kolaria was never affiliated with Kontentspace and does not support it.
</Warning>

## What to use instead

The Kolaria MCP server is still available and works with any MCP client, so you can get the same result without Kontentspace:

* Connect Cursor, Claude, opencode, or any other MCP client to Kolaria. See [MCP Server](/devtools/mcp) for the server URL, OAuth and API-key authentication, and the list of tools for posts, brand identities, integrations, and schedules.
* Choose the access level with API key scopes: a key with `posts.read` lets an agent browse and search posts; add `posts.write` so it can create and update them. See [Authentication](/api/authentication).

If you had a Kontentspace connection, revoke the API key you gave it from **API Keys** in the Kolaria dashboard.
