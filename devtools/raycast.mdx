The Kolaria Raycast extension brings your workspace into Raycast so you can browse posts, copy content, create new content, and manage brand identities and integrations without leaving your launcher.

  Install the Kolaria extension from the Raycast Store.
</Card>

## Commands

| Command | What it does |
| --- | --- |
| **List Content** | Browse and manage your Kolaria content |
| **Create Content** | Create new content with AI |
| **List Brand Identities** | Browse and manage your brand identities |
| **Create Brand Identity** | Generate a new brand identity from a website |
| **List Integrations** | Browse and manage your integrations |
| **Create Integration** | Add a new GitHub integration |

## Setup

The same guide is available in the dashboard under **Integrations > Raycast**.

<Steps>
  <Step title="Install the Kolaria extension">
    Open the Raycast Store, search for **Kolaria**, and install the extension.
  </Step>

  <Step title="Create a read and write API key">
    Head to **API Keys** in your dashboard, create a new key with read and write permissions for the resources you want to use in Raycast (posts, brand identities, integrations), and copy it.

    See [Authentication](/api/authentication) for details on creating and managing keys.
  </Step>

  <Step title="Configure the extension">
    Open Raycast, run any Kolaria command, and paste your API key when prompted.
  </Step>

  <Step title="Start using Kolaria in Raycast">
    Search and browse your posts, copy content, create content, and manage brand identities and integrations, all from Raycast.
  </Step>
</Steps>

<Tip>
  Read-only scopes are enough for browsing and copying. Grant write access for the resources Raycast should create or change, such as posts, brand identities, and integrations.
</Tip>

## Notes

- Treat the API key as a secret. Raycast stores it locally in its preferences store.
- Revoke and replace the key immediately if it is exposed.
